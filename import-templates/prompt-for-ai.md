# Как попросить нейросеть сделать файл со словами

Скопируйте один из промптов ниже в ChatGPT, Gemini, Claude, DeepSeek или любую другую
модель — и попросите сохранить ответ файлом. Полученный файл загружается в LexiFlow
на экране **«Импорт / экспорт»** (кнопка «Выбрать файл») или просто вставляется в поле
текстом.

Проще всего собрать промпт прямо в приложении: экран **«Промпт для нейросети»**
(в боковом меню рядом с «Импорт / экспорт») — там выбираются язык, тема, уровень, число слов
и количество примеров, а готовый текст можно скопировать или скачать. Файл ниже —
тот же набор формулировок на случай, если приложение под рукой нет.

---

## Промпт №1 — базовый (50 слов, пример на двух языках)

```text
Создай список из 50 английских слов по теме «Повседневная жизнь» уровня B1 для изучения русского человека.

Верни результат ТОЛЬКО как CSV-файл, без пояснений и без markdown-разметки (без ```).
Первая строка — заголовки ровно такие:
Слово,Перевод,Транскрипция,Пример,Перевод примера

Требования к строкам:
1. Слово — на английском, в начальной форме (для глаголов — с частицей to).
2. Перевод — на русском, кратко, можно несколько значений через запятую.
3. Транскрипция — в IPA, без квадратных скобок, например: ɔːlˈðəʊ
4. Пример — короткое предложение на английском, в котором есть это слово.
5. Перевод примера — точный перевод этого предложения на русский.
6. Если внутри значения есть запятая или кавычки — оберни всё поле в двойные кавычки:
   "хотя, несмотря на"
7. Никаких пустых полей и повторов слов.

Сохрани ответ в файл words.csv в кодировке UTF-8.
```

Меняйте в первой строке только три вещи: **язык**, **тему** и **уровень**.

## Промпт №2 — по два примера на слово

Добавьте в конец промпта №1:

```text
Дай по два примера на каждое слово: добавь в заголовки ещё две колонки — «Пример 2» и
«Перевод примера 2». Второй пример должен показывать другое значение или другой контекст.
```

## Промпт №3 — несколько колод в одном файле

```text
Добавь первой колонкой «Колода» и разложи слова по трём темам: «Еда», «Путешествия», «Работа».
Заголовки: Колода,Слово,Перевод,Транскрипция,Пример,Перевод примера
```

При импорте строки сами разойдутся по колодам с такими названиями (отсутствующие создадутся).

## Промпт №4 — JSON вместо CSV

```text
Верни результат ТОЛЬКО как JSON-файл без markdown-разметки, в таком виде:

{
  "app": "LexiFlow",
  "version": 1,
  "decks": [{ "name": "Английский: тема", "langFrom": "en", "langTo": "ru" }],
  "cards": [
    {
      "word": "although",
      "translation": "хотя, несмотря на",
      "transcription": "ɔːlˈðəʊ",
      "examples": [
        { "text": "Although it was late, we kept working.", "translation": "Хотя было поздно, мы продолжали работать." }
      ],
      "tags": ["союзы"]
    }
  ]
}

Поля id и srs не добавляй — приложение заполнит их само.
```

## Что делать с ответом модели

1. Если в чате есть кнопка **«Скачать» / «Download»** рядом с блоком кода — нажмите её
   и переименуйте файл в `words.csv`.
2. Если кнопки нет — скопируйте текст, вставьте в Блокнот (или любой текстовый редактор),
   сохраните как `words.csv` с кодировкой **UTF-8**.
3. Уберите обрамляющие ```` ``` ````, если модель их всё-таки добавила: строка должна
   начинаться сразу со `Слово,Перевод,…`.
4. В LexiFlow откройте **«Импорт / экспорт»**, выберите целевое: «создать новую колоду»
   или конкретную колоду, загрузите файл и нажмите **«Импортировать»**.

## Если импорт «не увидел» слова

| Симптом | Причина | Что делать |
| --- | --- | --- |
| Все слова попали в одну карточку | Модель отдала таблицу не через запятую | Попросите «строго CSV, разделитель — запятая» |
| Слово с переводом, но без примера | Модель забыла колонку | Сверьте заголовки: их должно быть ровно `Слово,Перевод,Транскрипция,Пример,Перевод примера` |
| Строки разъехались | В примере есть запятая, а поле не в кавычках | Добавьте в промпт: «все поля с запятыми оборачивай в двойные кавычки» |
| Всё пропущено как дубликаты | Слова уже есть в колоде | Отключите галочку «Пропускать дубликаты» или выберите другую колоду |

Файл `sample-en-ru.csv` в этой же папке — рабочий пример на 10 слов: его можно
импортировать как есть, чтобы проверить, что всё работает.
