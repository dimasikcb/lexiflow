## 3. Архитектура в двух словах

Ванильный JS, ES5, без сборки, IIFE-модули на глобальном `App`.
Порядок скриптов в `index.html`:

```
util → srs → store → speech → ttsnet → model-tts → qr → sync → notify → streak
→ quicksettings → views/* → app
```

- Хранилище: `localStorage`, ключ `lexiflow.data.v1` (`js/store.js`).
- `S.syncPayload()` при каждом вызове ставит свежий `updatedAt` — поэтому
  побайтово сравнить «нашу копию» невозможно; сравнение с последней
  записанной строкой (`lastWritten`).
- Версия: `js/app.js` (`APP_VERSION`) + `sw.js` (`VERSION`) — **поднимать
  обязательно вместе**, иначе SW отдаёт старое.

Папки рядом: `lexiflow-deploy3` — копия для публикации (синхронизация:
`node tools/sync-deploy.js`). `lexiflow-deploy` / `lexiflow-deploy2` — старьё,
не трогать.

## 5. Ловушки, на которые уже наступали

1. **`localStorage` + `reload` в тестах молча теряются.** `pagehide` зовёт
   `S.flush()` и перезаписывает твой набор. Заливать данные только через API:
   `App.store.wipe()` + `App.store.replaceAll(data, 'replace')`.
2. **Внутри `page.evaluate` нет доступа к переменным скрипта** — передавать
   параметром (`page.evaluate(fn, arg)`).
3. **Headless Chromium всегда отдаёт `Notification.permission = 'denied'`**,
   `grantPermissions` не помогает. Сценарии «разрешено» эмулировать
   `addInitScript` со заглушкой `Notification`.
4. `tools/check-mobile.js` без `NODE_PATH` падает с `MODULE_NOT_FOUND`.
5. Сеть до `agentos-app.run` иногда не даёт `page.goto` уложиться в 30 с —
   это транзиентные таймауты хостинга, не поломка приложения; перезапустить.
6. `pagehide` + вкладка в фоне: таймеры представляются замороженными —
   сверять интервалы по стенным часам (`Date.now()`), не по количеству тиков.

## 6. Что было сделано в последнем заходе (v1.18.6, не опубликовано)

- **Баг дневного лимита:** `maxReviewsPerDay` ограничивал размер ОДНОЙ
  сессии, а не день. Проверено в браузере: 5 ответов уже сделано, лимит 5 —
  новая сессия всё равно отдавала 5 карточек. Исправлено:
  `App.store.reviewsDoneToday()` (считает только `review`/`relearning`, без
  теста и шагов обучения) + `reviewsLeftToday()` в `study.js`; по тому же
  правилу считаются «Продолжить» и итоги. Стартовый экран честно объясняет
  урезанную сессию строкой `.nudge--limit`.
- **Тема:** `--bg-card` и `--text-muted` в CSS не существовали — кнопка и
  шторка быстрых настроек были чёрными в светлой теме. Заменены на `--panel`
  и `--text-mute`.
- Проверено в браузере: `tools/check-daily-limits.js` — 18 проверок
  (остаток дня, исчерпание, обучение/тест, вчерашние ответы, `newPerDay`).
- Прогнано всё: контракт, 1160 юнит-тестов, локальный E2E и **живой E2E по
  опубликованному адресу** (`ОШИБКИ КОНСОЛИ: 0`).
- SRS «Трудно» проверен численно: `hardInterval` работает и на первом повторе
  выпущенной карточки (10 дн → 12 дн), шаг фиксируется только на обучении —
  это поведение Anki, а не баг.
